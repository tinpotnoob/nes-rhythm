## Description

Song list:
- Beethoven Virus

Current features:
- Menu, pause, restart
- Configurable music offset
- 1x and 2x speed
- High scores

PC Controls:
| NES Button | P1 | P2 |
| --- | --- | --- |
| D-PAD | ←↑↓→ | WASD |
| A | Space | T |
| B | Shift | R |
| SELECT | \ | F |
| START | Enter | G |


## Getting Started

Simply upload the files to the 8bitworkshop IDE. To run on the NES or an emulator, go to menu, then click Download > Download ROM Image.
